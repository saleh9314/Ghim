# Ghim

صفحة تعريفية عربية لشقق غيم المفروشة في بريدة. الموقع ثابت، ويعرض الوحدتين وصورهما وموقعهما وروابط التواصل والحجز الخارجية؛ لا يحتاج إلى تثبيت حزم أو بناء المشروع.

## التشغيل المحلي

من مجلد المستودع:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

## الاختبارات

تعمل اختبارات الصفحة بالمكتبة القياسية لبايثون دون حزم إضافية:

```sh
python3 -m unittest discover -s tests -v
```

تتحقق الاختبارات من مواصفات الوحدتين، والعنوان المختصر، ومقاسات النصوص، وصحة الروابط الداخلية، ووجود ملفات الصور، والمحافظة على روابط منصات الحجز.

## تحديث المحتوى

معلومات غيم 01 وغيم 02 في `index.html`. مصادر المواصفات وقرارات الحفاظ على الهوية موثقة في [وثيقة الهوية والمحتوى](docs/brand-spec.md). حدّث المواصفات إذا تغيرت إعدادات الوحدتين في إعلاناتهما الأصلية.
